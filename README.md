One word for your Wi-Fi: **Ghosting**. A small program that writes that single word to `/output/entry.txt` for make.fun's "One Word for Your Wi-Fi" bounty. The Wi-Fi vanishes mid-call, mid-game, mid-download — right when you need it most.

## Run it

```sh
node main.ts
```
